# ARCH design · studio — сайт студии

Статический сайт: HTML + CSS + JS, без сборки, зависимостей и внешних запросов.
Открывается как обычная папка на любом хостинге.

```
arch-design-studio/
├── index.html          вся разметка + SVG-спрайт иконок
├── styles.css          дизайн-система (токены, сетки, адаптив)
├── script.js           меню, анимации, калькулятор, отправка заявок
├── config.js           ← ЕДИНСТВЕННЫЙ файл для настройки CRM и цен
├── assets/
│   ├── fonts/          SF Pro Display (5 начертаний, woff2, сабсет)
│   ├── logo-mark.svg   знак (вектор из брендбука)
│   ├── logo-full.svg   логотип с надписью
│   ├── team/           портреты команды (ч/б, 4:5)
│   └── compare/        пара «3D / фото» для блока сравнения ← ЗАМЕНИТЬ
└── server/             приём заявок в Telegram (PHP / Node)
```

---

## 1. Запуск

```bash
python -m http.server 4321 --directory arch-design-studio
```

Открыть `http://localhost:4321`. Можно просто открыть `index.html` двойным
кликом — всё работает и с `file://`.

## 2. Калькулятор + заявки в Telegram

Заявки уходят из двух мест: калькулятора и формы «Бесплатный замер».

**Настройка — 5 минут:** см. [`server/README.md`](server/README.md).
Коротко: создать бота у `@BotFather`, узнать `chat_id`, залить
`server/telegram-proxy.php` на хостинг и вписать адрес в `config.js`:

```js
crm: { endpoint: 'https://ваш-домен.kz/api/lead.php' }
```

Если ничего не настроено — заявка не теряется: открывается WhatsApp
менеджера с уже готовым текстом.

### Цены калькулятора

Вся ценовая модель — в `config.js`, блок `calc`. Менять цифры можно
без программиста:

| Что | Где | Пример |
|---|---|---|
| Цена пакета за м² | `calc.packages` | `classic: { min: 4000, max: 7000 }` |
| Наценка за тип объекта | `calc.objects` | `house: { k: 1.15 }` = +15% |
| Цена доп. опции за м² | `calc.options` | `supervision: { price: 1100 }` |
| Наценка за срочность | `calc.urgency` | `fast: { k: 1.20 }` = +20% |
| Скидка за объём | `calc.volumeDiscount` | от 300 м² → `k: 0.90` |

Формула: `(цена пакета + опции) × площадь × коэф. объекта × срочность × скидка`.
Опции, входящие в пакет, автоматически помечаются «в пакете» и не суммируются
дважды.

## 3. Аналитика (без неё конверсию не измерить)

В `config.js` → `analytics` впишите номер счётчика Яндекс.Метрики и/или
идентификатор GA4, а сам код счётчика вставьте в `<head>` по инструкции сервиса.
Дальше события уходят сами:

| Событие | Когда срабатывает |
|---|---|
| `lead_form` | отправлена форма «Бесплатный замер» |
| `lead_calc` | отправлен расчёт из калькулятора (с пакетом, площадью и суммой) |
| `compare_used` | посетитель подвигал слайдер «3D → факт» |
| `cases_filter` / `cases_more` | фильтр кейсов, «показать ещё» |
| `click_phone` / `click_whatsapp` | клик по телефону или WhatsApp |
| `cta_hero_calc`, `cta_compare`, … | клики по кнопкам с атрибутом `data-track` |

Ключевые цели для настройки в Метрике: `lead_form` и `lead_calc`.
Для отладки поставьте `analytics.debug = true` — события будут печататься в консоль.

## 4. Что заменить перед публикацией

1. **Фото команды — уже стоят реальные.** `assets/team/aset.jpg`,
   `nurzat.jpg`, `abylai.jpg`: кроп 4:5, переведены в ч/б под монохромную
   палитру сайта. Если понадобится заменить — пересоберите тем же скриптом
   или положите файлы 4:5 с теми же именами.

2. **Фото кейсов** — в блоке «Кейсы» сейчас сгенерированные CSS-подложки
   в стиле чертежа (`.case__img--a … --f` в `styles.css`). Замените на фото:
   ```html
   <div class="case__img"><img src="assets/cases/1.jpg" alt="..."></div>
   ```
   Тексты кейсов (площади, годы, состав работ) — в атрибутах
   `data-title`, `data-meta`, `data-scope` у каждой карточки; они же попадают
   в модальное окно.

3. **Блок «3D → факт»** — `assets/compare/viz.svg` и `photo.svg`.
   Это ключевой конверсионный элемент: он снимает главный страх заказчика
   («на картинке одно, в жизни другое»). Нужна пара **одного и того же
   помещения**: 3D-визуализация и фото после реализации, снятое **с той же
   точки**. Формат 3:2, например 1800×1200. Замените `src` у обеих картинок
   в секции `#compare` и подпись под ними.

4. **Отзывы** — секция `#reviews` помечена `data-placeholder="true"`.
   Тексты внутри — рыба, а не слова клиентов, публиковать их как отзывы нельзя.
   Замените на реальные (имя, объект, текст) и уберите атрибут
   `data-placeholder`. Если реальных отзывов пока нет — удалите секцию целиком,
   пустая заглушка хуже, чем её отсутствие.

5. **Домен в SEO-разметке.** В `index.html` (`canonical`, `og:url`, `og:image`,
   блок JSON-LD), в `robots.txt` и `sitemap.xml` сейчас стоит
   `https://arch-design.kz/` — замените на боевой домен.
   `AggregateRating` в разметку сознательно не добавлен: рейтинг можно
   размечать только при реальных публичных отзывах, иначе это нарушение правил
   Google и риск санкций.

6. **Контакты и реквизиты** — продублированы в `config.js` и в подвале
   `index.html`.

7. **После любых правок** поднимите версию в трёх ссылках вверху/внизу
   `index.html` (`?v=3.0` → `?v=3.1`) — иначе браузеры посетителей будут
   показывать старый CSS из кэша.

## 5. Как устроена мобильная плотность

Страница на мобильном занимает ~15 500 px (19 экранов) вместо 21 500 (26.5).
Контент при этом **не удалён** — изменилась только раскладка, поэтому
для поиска страница осталась полной:

| Приём | Где |
|---|---|
| 2 колонки вместо 1 | услуги, преимущества |
| Горизонтальные карусели | тарифы, команда, отзывы |
| Показ 3 кейсов + «Показать ещё» | портфолио |
| Доп. опции свёрнуты в аккордеон | калькулятор |
| Этапы свёрнуты до 2 строк, раскрываются тапом | процесс |
| Реквизиты под спойлером | подвал |
| План-иллюстрация скрыта | hero (её роль берёт блок «3D → факт») |

Всё это включается только на ширине ≤620 px. Десктоп не изменился.

## 6. Что уже сделано

**UX**
- Липкая шапка с индикатором прочитанного и подсветкой активного раздела
- Мобильное меню + нижняя панель действий (Позвонить / WhatsApp / Расчёт)
- Калькулятор с живым пересчётом и отправкой в Telegram
- Кейсы: фильтр по типам + модальное окно с составом работ
  (открывается кликом и с клавиатуры)
- FAQ-аккордеон, маска телефона `+7 (___) ___ __ __`, валидация форм
- Тосты-уведомления об отправке

**Доступность и производительность**
- Ноль внешних запросов: шрифты, иконки и графика — локальные
- Шрифты сабсетнуты под кириллицу и казахские буквы: 5 начертаний ≈ 148 КБ
- Иконки — один инлайновый SVG-спрайт, 30 знаков, штрих 1.4 на сетке 24
- Полная поддержка `prefers-reduced-motion` и печати
- Видимый фокус на всех интерактивных элементах, `aria`-атрибуты, skip-link
- Нет горизонтальной прокрутки от 375 до 1440 px

**Палитра — монохром с одним акцентом**
| Токен | Значение | Роль |
|---|---|---|
| `--ink` | `#0D0D0D` | шапка hero, процесс, подвал, кнопки |
| `--paper` / `--paper-2` | `#FFFFFF` / `#F5F3F0` | светлые секции |
| `--beige` | `#C9BCA8` | единственный акцент: выделения, иконки, ховеры |
| `--beige-soft` | `#E8E2D8` | фон блока заявки |
| `--line` | `#E4E0DA` | волосяные линии вместо рамок и теней |

Оранжевый и жёлтый из брендбука на сайте не используются — по вашему
решению сайт чёрно-белый. Логотип тоже переведён в один тон (`#0D0D0D`,
в подвале инвертируется в белый); исходные цветные файлы остались в PDF.

## 7. Про шрифты — важно

Сайт использует **SF Pro Display** (Apple). Лицензия Apple разрешает
применять эти шрифты для интерфейсов приложений под платформы Apple;
использование в качестве веб-шрифта на коммерческом сайте ею **не покрыто**.
Файл лицензии — в исходной папке шрифтов.

Если это важно для вас, замена делается одной строкой в `styles.css`:

```css
--f: 'Inter', 'Manrope', -apple-system, 'Segoe UI', Roboto, sans-serif;
```

Inter — бесплатная альтернатива с почти той же метрикой и полной кириллицей.
Вся типографика сайта построена на переменной `--f`, ничего больше менять
не придётся.

## 8. Движение

Анимации собраны из четырёх примитивов, всё на CSS-переходах, без библиотек:

| Класс | Что делает | Где применяется |
|---|---|---|
| `.reveal` | подъём + проявление | почти все блоки |
| `.rv-mask` | строка выезжает из-под кромки | `h1`, все `h2` (обёртка ставится скриптом) |
| `.rv-img` | шторка уходит вверх, кадр добирает масштаб | портреты команды, блок сравнения |
| `.rv-line` | линия прочерчивается слева направо | разделители |

Карточки внутри одной сетки появляются с шагом 80 мс (переменная `--d`).
Кейсы раскрываются отдельно — увеличением их фонового слоя.

**Три страховки, чтобы контент не пропал:**
1. Анимации включаются только классом `js` на `<html>` — без JS страница
   просто отрисована.
2. Через 2.5 с всё, что попало в кадр, показывается принудительно.
3. При возврате на вкладку показывается всё видимое — в фоновых вкладках
   браузер останавливает `requestAnimationFrame` и наблюдатель молчит.

`prefers-reduced-motion` отключает движение полностью.
