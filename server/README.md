# Подключение Telegram-бота (CRM для заявок)

Заявки с формы и из калькулятора уходят в Telegram-чат менеджеров.
Есть три варианта — выберите один.

---

## Шаг 0. Создать бота и узнать chat_id (нужно для любого варианта)

1. В Telegram откройте **@BotFather** → `/newbot` → задайте имя и username.
   BotFather выдаст **токен** вида `7712345678:AAH...` — он секретный.
2. Создайте группу «Заявки с сайта» и добавьте туда бота
   (или пишите в личку — тогда chat_id будет вашим).
3. Узнать `chat_id`:
   - напишите в группу любое сообщение;
   - откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`;
   - найдите `"chat":{"id":-1001234567890 …}` — это и есть `chat_id`
     (у групп он с минусом).
   Альтернатива: бот **@userinfobot** покажет ваш личный id.

---

## Вариант A — PHP-хостинг (самый простой для .kz-хостингов)

1. Залейте `telegram-proxy.php` на хостинг, например в `/api/lead.php`.
2. Пропишите токен. Лучше через переменные окружения, но на shared-хостинге
   проще прямо в файле — замените первые две строки настроек:
   ```php
   $BOT_TOKEN = '7712345678:AAH...';
   $CHAT_ID   = '-1001234567890';
   $ALLOWED   = ['https://ваш-домен.kz'];
   ```
3. В `config.js` сайта укажите:
   ```js
   crm: { endpoint: 'https://ваш-домен.kz/api/lead.php', ... }
   ```
4. Проверьте:
   ```bash
   curl -X POST https://ваш-домен.kz/api/lead.php -H "Content-Type: application/json" -d "{\"phone\":\"+7 700 000 00 00\",\"name\":\"Тест\",\"source\":\"Проверка\"}"
   ```

Заявки дополнительно пишутся в `leads.csv` рядом со скриптом —
удобно выгружать в Excel. Файл закройте от публичного доступа (`.htaccess`).

---

## Вариант B — Vercel / Netlify / Cloudflare (бесплатно, без своего сервера)

1. Загрузите проект в GitHub, подключите к Vercel.
2. Положите `lead.js` в папку `api/` (для Netlify — `netlify/functions/`).
3. В настройках проекта → **Environment Variables** добавьте:
   | Переменная | Значение |
   |---|---|
   | `TG_BOT_TOKEN` | токен от BotFather |
   | `TG_CHAT_ID` | id чата менеджеров |
   | `ALLOWED_ORIGIN` | `https://ваш-домен.kz` |
4. В `config.js`: `endpoint: 'https://ваш-проект.vercel.app/api/lead'`.

---

## Вариант C — без сервера (только для теста)

В `config.js` заполните:
```js
telegram: { botToken: '7712345678:AAH...', chatId: '-1001234567890' }
```
Заявка уйдёт напрямую из браузера.
**Важно:** токен будет виден любому посетителю в исходном коде страницы.
Годится для быстрой проверки, но для боевого сайта используйте вариант A или B.

---

## Запасной путь

Если ничего не настроено, сайт не теряет заявку: она открывается
в WhatsApp менеджера уже готовым текстом (`crm.whatsapp` в `config.js`).
